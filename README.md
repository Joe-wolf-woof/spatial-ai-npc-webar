# Spatial AI NPC

物理空間を認識して自律行動する WebAR エージェント。

スマホのカメラ越しに3Dアバター（AIエージェント）が出現し、マルチモーダルAIが現実空間の物体や状況を認識して、文脈に応じた雑談・作業サポートを音声対話とモーションで返す、アプリ不要のWebAR体験を目指すポートフォリオ作品。

## 現在の状態：Phase 3（ハイブリッド化）

- three.js で3Dアバター（プレースホルダー）をブラウザに表示し、地面の影で接地感を表現
- 「話しかける」ボタン → AIが `{ text, emotion }` のJSONで返答 → Web Speech API で読み上げ、感情タグに応じてアバターが動く
- 「カメラを開始」→ カメラ映像がステージ背景になり、アバターが重なる
- 「いまの様子を見て話す」→ 現在のフレーム（長辺768pxに縮小したJPEG）を Gemini に送り、空間の状況に応じた声かけを返す。10秒ごとの自動観察も可能
- ローカル検知（COCO-SSD）がカメラ映像を1.5秒間隔で推論し、物体名・信頼度・推論msを即表示。新しい物体が現れたときだけ Gemini へ自動で問い合わせる（仮説Aのハイブリッド構成）
- ローカル検知msとGemini応答msを並べて表示。ベースライン実測は 11,442 ms（Phase 2・スマホ実機）
- Gemini API キーを設定すれば実API応答、未設定ならモック応答で動作確認可能（視覚連動のモックは固定文）
- モデルは3.x系から自動フォールバック（新規キーでは2.x系が404になるため）

## アーキテクチャ

```
├─ index.html / main.js        … 画面と配線（UIイベント → AI → 音声・モーション）
├─ ar-viewer/                  … 3D表示（シーン、アバター）
│   ├─ scene.js                … レンダラ、カメラ、ライト、影。GLTF読込も担当
│   └─ avatar.js               … プレースホルダーアバター（実モデルへ差替予定）
├─ ai-agent-engine/            … AIと発話
│   ├─ gemini-client.js        … Gemini API クライアント（応答は {text, emotion} のJSON契約）
│   └─ speech.js               … Web Speech API による読み上げ
├─ motion-controller/          … 感情タグ → モーション変換
│   └─ motion-controller.js    … idle / happy / thinking / pointing
└─ assets/models/              … avatar.glb を置くと自動で実モデルに差し替わる
```

## 仮説と検証（本作品の設計判断）

### 仮説A：レスポンス遅延の克服
- 問い：カメラ画像を毎回LLMに送ると応答が5秒以上かかり、体験が損なわれるのではないか。
- 計測（Phase 2・スマホ実機）：毎回 Gemini へ画像を送る方式の応答は **11,442 ms**（2026-11-10 実測）。仮説は裏付けられた。
- 対応方針（Phase 3で実装）：ローカルの軽量物体検知（TensorFlow.js / COCO-SSD、lite_mobilenet_v2）で1.5秒間隔に一次判定して即表示し、Geminiへ画像を送るのは「新しい物体クラスが現れたとき（20秒クールダウン付き）」と「ユーザーが明示的に聞いたとき」だけに絞るハイブリッド構成。
- 画面下部に「ローカル検知 ms ／ Gemini応答 ms」を常時並べて表示し、before/after を比較できるようにした。

### 仮説B：空間UIとアバターの立ち位置
- 問い：アバターが映像の中で浮いて見えると没入感が削がれるのではないか。
- 対応方針：平面検知（Raycast）で床・机上に影とともに設置する。Phase 1では固定地面＋ShadowMaterialで最小実装済み。

## ロードマップ

- Phase 1（済）：最小構成 — 3D表示＋ボタンでAI応答を読み上げ
- Phase 2（済）：視覚情報の連動 — カメラフレームを Gemini へ送り、空間の状況に応じた声かけを返す（手動＋10秒間隔の自動観察、応答時間の表示）
- Phase 3（一部済）：ハイブリッド化 — ローカル物体検知（COCO-SSD）との統合と遅延の比較表示（仮説Aの実装・検証）。残りは感情タグによる表情・モーションの本格化と実モデル対応
- Phase 4：構造化・発信 — 技術記事、リポジトリ整理、1分デモ動画

## 起動方法

ES Modules を使うため、ローカルサーバー経由で開く（ファイルを直接開くと動きません）。

```powershell
# 例：Python が入っている場合（このフォルダで実行）
python -m http.server 8000
# → ブラウザで http://localhost:8000 を開く
```

VS Code の Live Server 拡張でも可。スマホで試す場合は HTTPS 環境（または同一LAN＋適切な設定）が必要（カメラ利用は Phase 2 以降）。

## メモ

- Gemini API キーは画面の「設定」から入力し、ブラウザの localStorage にのみ保存されます。コードやリポジトリにキーを直書きしないこと。
- 実モデルを使う場合は GLTF 形式で `assets/models/avatar.glb` に配置してください。
